# Wordblend · 中英混排阅读

**把一页文章变成你能读下去的样子。**
中文网页夹几个英文词，英文网页夹几个中文词，点一下就看见释义。

离线词典 · 零联网 · 零账号 · 开源

## 这是什么

大多数人读英文资料的真实状态是：句子能看懂七成，卡在几个词上，来回切翻译软件，读三行就放弃。

Wordblend 换了个思路：**不翻译整页，只替换一部分词**。

- 在**中文网页**里，按你的强度把词库里的中文词换成英文（中 → 英），熟悉的语境托着你，生词自然出现；
- 在**英文网页**里，把一部分英文词换成中文（英 → 中），理解不再中断，同时保留了英文原句；
- 点任意被替换的词，弹出音标、释义、同根词、近义/反义——**往回查**只要一下。

强度 1~10，1 最密、10 最淡。词库 18 个，可多选，选得越多、档位越密，替换得越多。

## 特性

| | |
|---|---|
| **双向** | 中文页夹英文、英文页夹中文，各有一套独立的强度与词库 |
| **离线** | 词典全部打包在扩展里，不请求任何服务器，不采集任何数据 |
| **可调密度** | 1~10 档；英→中按段落词数分配，长文从头到尾密度一致 |
| **难度分层** | 英→中优先替换生僻词，最常用的那批词按档位逐步退出 |
| **站点黑白名单** | 全部网站 / 仅白名单 / 黑名单，支持 `*.example.com` |
| **按站锁语言** | 自动判定不准时，可在站点规则里把某个站固定成中文页或英文页 |
| **点词看释义** | 音标、中释义、同根词、近义、反义；点空白关闭 |
| **不打断页面** | 只改文本节点，不动结构、样式和链接；按钮照常点、链接照常跳 |

## 安装

**应用商店**（审核中时请用下面的本地安装）

- Chrome Web Store：待上架
- Microsoft Edge 加载项：待上架
- 油猴脚本：`dist/Wordblend.user.js`（Tampermonkey / Violentmonkey）

**本地安装（开发者模式）**

1. 下载 `Wordblend-v2.1.0.zip` 并解压；
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」；
3. 点「加载已解压的扩展程序」，选择解压出来的目录（含 `manifest.json` 的那一层）；
4. 点工具栏的 Wordblend 图标即可调强度、词库和站点规则。

## 使用

- **总开关**：右上角，关掉整页立刻还原成原文，统计归零。
- **页面语言**：自动 / 中文页 / 英文页。默认自动，按正文汉字占比判定；判错时手动指定一次即可。
- **强度**：中文页越高换得越多；英文页 1 最密、10 最淡。
- **词库**：四组 18 个（基础 / 进阶 / 专业 / 垂直），两个方向各选各的。
- **站点**：切到「黑名单」把某个站加进来，它就不替换了；「仅白名单」是反过来只替换名单里的站。每条规则还能单独锁定语言。
- 点被替换的词 → 释义卡片；`Esc` 或点空白关闭。

## 开发

```bash
# 弹窗（Vue 3 + Vite + Tailwind）
cd popup
pnpm install
pnpm build          # 输出到 src/popup-dist

# 打包扩展 / 油猴脚本 / zip
cd ..
python build.py     # 输出到 dist/
```

目录：

```
src/core.js          内容脚本（词典解析、替换、卡片、站点规则、设置同步）
src/popup-dist/      弹窗构建产物（由 popup/ 生成，勿手改）
popup/               弹窗源码（Vue 3 + Tailwind）
data/                词典数据（构建时内联进 content.js）
tools/make_icon.py   图标生成（纯标准库写 PNG）
docs/manual.txt      面向用户的说明
docs/store/          商店上架材料
build.py             构建脚本
```

数据规模：中 → 英 17,032 条、释义 13,594 条、英 → 中 21,347 条、词形变化 6,877 条。

## 隐私

不联网、不埋点、不要账号。设置只存在 `chrome.storage.sync`（跟着浏览器账号同步），页面文本只在本地处理，不发送到任何地方。

详见 [docs/store/privacy.md](docs/store/privacy.md)。
